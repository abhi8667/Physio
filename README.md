## 🔍 Overview

**PhysioTracker AI** is a full-stack, AI-driven physiotherapy platform that replaces generic YouTube exercise videos with a personalised, computer-vision-monitored rehabilitation experience. Describe your injury, receive a clinically-aware exercise programme generated by **Google Gemini 2.5 Flash**, then perform your exercises while a **MediaPipe Pose** engine counts your reps and flags form errors — all in real time through your webcam.

> No physiotherapist appointment needed to get started. No guesswork about whether your form is correct.

---

## 🚨 Problem Statement

Musculoskeletal injuries affect hundreds of millions of people globally. The rehabilitation journey is plagued by:

- 🕐 **Long wait times** for physiotherapy appointments
- 💸 **High cost** of repeated in-person sessions
- ❓ **Zero feedback** when exercising alone at home
- 📉 **Poor adherence** due to boring, one-size-fits-all programmes
- 📋 **No progress tracking** between appointments

Patients are sent home with a printed sheet of exercises and left to their own devices — and outcome data suffers as a result.

---

## ✅ Solution

PhysioTracker AI delivers a three-step intelligent rehabilitation loop:

| Step | What Happens |
|------|-------------|
| **1. AI Intake** | Describe your injury and rate your pain (0–10). Gemini AI reads a curated exercise catalogue and generates a prioritised, personalised programme with confidence scores and safety cautions. |
| **2. CV Exercise Session** | Perform your exercises in front of a webcam. MediaPipe Pose detects your skeleton in real time, counts reps, detects form errors (e.g. knee cave, elbow drift), and overlays live feedback on the video feed. |
| **3. Analytics & Reports** | Review adherence charts, form error trends, activity heatmaps, muscle-group distribution, and AI-generated clinical recommendations. |

---

## ✨ Features

- 🤖 **AI-Personalised Exercise Plans** — Gemini 2.5 Flash generates sets/reps/caution for each exercise tailored to the patient's exact complaint and pain level
- 🎥 **Real-Time Pose Estimation** — MediaPipe Pose skeleton overlay with rep counting via state-machine logic
- ⚠️ **Live Form Error Detection** — Detects and logs specific errors: `knee_cave`, `elbow_drift`, `hyperextension`, `knee_over_toe`, `shoulder_rise`, `bouncing`, and more
- 📊 **Interactive Analytics Dashboard** — Activity heatmap (28 days), accuracy trend chart, muscle-group distribution, streak counter, recovery score
- 💬 **AI Insights Engine** — Session history fed back to Gemini for personalised dashboard suggestions and formal clinical report recommendations
- 🗂️ **15+ Physiotherapy Exercises** — Squat, lunge, knee extension, shoulder flexion/abduction, bicep curl, wall push-up, single-leg stand, cat-cow, bird dog, seated forward bend, neck lateral flexion, hip abduction, jumping jacks, high knees
- 🔌 **REST API + WebSocket** — FastAPI backend exposes a full REST API and a WebSocket endpoint for the real-time CV pipeline
- 🗄️ **Persistent Session Logging** — SQLite database stores every session, rep count, form error, and assessment for longitudinal tracking
- 📈 **Adherence Metrics** — Per-exercise completion rate vs. prescribed plan
- 👤 **Multi-User Support** — Multiple patient profiles, each with their own history and plans

## 🏗️ Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                      Streamlit Frontend                      │
│  ┌──────────────┐  ┌───────────────────┐  ┌─────────────┐  │
│  │  1_Intake.py │  │ 2_Exercise_Session│  │ 3_Reports.py│  │
│  │  (AI intake) │  │  (CV + WebSocket) │  │ (analytics) │  │
│  └──────┬───────┘  └────────┬──────────┘  └──────┬──────┘  │
└─────────┼───────────────────┼────────────────────┼──────────┘
          │ HTTP POST          │ WebSocket           │ HTTP GET
          ▼                    ▼                     ▼
┌─────────────────────────────────────────────────────────────┐
│                       FastAPI Backend (api.py)               │
│  /users  /assessments  /exercise-plans  /sessions  /reports  │
│  /analytics  /insights  /ws/session/{user_id}/{exercise_id} │
└────────┬────────────────────┬────────────────────┬──────────┘
         │                    │                     │
         ▼                    ▼                     ▼
┌──────────────┐    ┌─────────────────┐   ┌──────────────────┐
│  llm_client  │    │   cv_engine/    │   │   database.py    │
│  (Gemini API)│    │  evaluator.py   │   │  (SQLAlchemy ORM)│
│              │    │  utils.py       │   │                  │
│  Plan Gen  + │    │  MediaPipe Pose │   │  Users           │
│  Insights    │    │  State Machines │   │  Assessments     │
└──────────────┘    └─────────────────┘   │  ExercisePlans   │
                                           │  SessionLogs     │
                                           └──────────────────┘
```

### Key Design Decisions

- **CV Engine isolation** — `cv_engine/` is a lazy-loaded module; if MediaPipe fails to import (e.g. on CI), the API degrades gracefully and only WebSocket sessions are disabled.
- **Confidence filtering** — Gemini returns a `confidence` score (0–1) per exercise. Items below **0.6** are automatically discarded before persisting to the database.
- **State-machine rep counting** — Each exercise has a dedicated `_eval_<exercise_id>` method in `ExerciseEvaluator` using a phase state machine (e.g. `STANDING → SQUATTING → STANDING`) for robust, noise-resistant counting.
- **Model fallback** — LLM client tries `gemini-2.5-flash` first, then falls back to `gemini-2.0-flash` with up to 3 exponential-backoff retries per model.
- **Dual interface** — The app ships both a Streamlit UI (for end users) and a full FastAPI REST + WebSocket backend (for API consumers or future mobile clients).

## ⚡ Installation

### Prerequisites

- Python 3.10+
- A [Google Gemini API key](https://aistudio.google.com/app/apikey)
- Webcam (for exercise sessions)

### 1. Clone the repository

```bash
git clone https://github.com/abhi8667/Physio.git
cd Physio
```

### 2. Create and activate a virtual environment

```bash
python -m venv venv
source venv/bin/activate      # macOS / Linux
venv\Scripts\activate         # Windows
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

```bash
cp .env.example .env
```

Edit `.env` and add your Gemini API key:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

## 🚀 Usage

### Option A — Streamlit App (Recommended)

```bash
streamlit run frontend/app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser, then follow the three-step flow:

1. **Intake** — Enter your name, describe your complaint, set pain level, click *Generate My Plan*.
2. **Exercise Session** — Select an exercise, allow webcam access, perform your reps.
3. **Reports** — Review your charts and progress history.

### Option B — FastAPI Backend Only

```bash
uvicorn api:app --reload
```

Browse the interactive API docs at [http://localhost:8000/docs](http://localhost:8000/docs).

#### Quick API Example

```bash
# Create a user
curl -X POST http://localhost:8000/users \
     -H "Content-Type: application/json" \
     -d '{"name": "Alex"}'

# Generate an exercise plan (user_id=1)
curl -X POST http://localhost:8000/users/1/assessments \
     -H "Content-Type: application/json" \
     -d '{"complaint": "Right knee pain after running", "pain_level": 5}'

# Retrieve the plan
curl http://localhost:8000/users/1/exercise-plans
```
